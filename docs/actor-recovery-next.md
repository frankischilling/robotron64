This recovery pass confirms that `func_8001CF68` is the complete actor resource loader from `0x8001CF68` through `0x8001D260`, for 760 bytes. The earlier `0x8001D248` limit falls inside its epilogue. A loaded resource returns `2`; a new load returns `1`. The matching source tests `entry->word04.fields.flags06.bits.loaded` before loading. Using the named loaded bit, rather than a signed comparison of the complete 16-bit flags value, also gives IDO the target temporary-register allocation. The current source matches all 760 bytes with IDO 5.3 at `-O2 -G 0 -non_shared -mips1 -32`.
